# О проекте
Фондконтроль - это CRM-система для фондов помощи животным. Система призвана автоматизировать все процессы в организациях и систематизировать хранение данных. Текущий репозиторий представляет собой frontend-часть проекта.

# Стек
- React
- Typescrypt
- Redux Toolkit
- Webpack
- SCSS
- Axios

# Установка

### Требования
- Node.js версии 20 или выше ([https://nodejs.org](https://nodejs.org/))  
- Git версии 2.46 или выше ([https://git-scm.com](https://git-scm.com/))

### Инструкция
1. Клонируйте репозиторий, обратите внимание, команда с точкой в конце для загрузки в текущую директорию
```bash
git clone https://github.com/eujeniogonzalez/drmsystem-frontend.git .
```

2. Установите зависимости
```bash
npm install
```

3. Запустите проект
```bash
npm start
```

Проект готов к работе. В настройках указан удалённый dev API сервер, все обращения происходят к нему. Для входа в личный кабинет предварительно необходимо зарегистрироваться, подтвердить электронную почту и войти в свою учётную запись.
